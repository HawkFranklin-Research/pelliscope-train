# Citation ledger

The final release must cite and version the following sources.

| Component | Required citation or record |
|---|---|
| SCIN data | Original SCIN dataset paper, dataset card, license, and immutable dataset revision |
| ResNet-50 | He et al.; torchvision weights revision |
| Inception-v3 | Szegedy et al.; torchvision weights revision |
| BiT-50 | Kolesnikov et al.; exact Hugging Face model revision |
| ViT-Base | Dosovitskiy et al.; exact Hugging Face model revision |
| CLIP ViT-B/32 | Radford et al.; exact model revision |
| Derm Foundation | Google Health dermatology foundation-model release, access terms, and archive hash |
| SigLIP2 SO400M | SigLIP2 paper/model card and exact model revision |
| Gated-attention MIL | Ilse, Tomczak, and Welling, 2018 |
| Class-balanced loss | Cui et al., effective number of samples |
| Iterative multilabel stratification | Sechidis, Tsoumakas, and Vlahavas; `iterative-stratification` version |
| Software | Python, NumPy, pandas, SciPy, scikit-learn, PyTorch, torchvision, Transformers, TensorFlow when used, Pillow, Matplotlib, and seaborn |
| Closed APIs | Provider, exact dated model identifier, access date, request parameters, prompt hash, and parser version |

`CITATION.cff` provides repository-level attribution. Conventional references belong in the manuscript bibliography; model revisions and artifact hashes belong in the run and artifact ledgers.
